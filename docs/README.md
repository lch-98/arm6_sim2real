## 용어

| 용어 | 뜻 |
|---|---|
| 기준선 (baseline) | 실물과 비교하기 위해 시뮬레이션에서 먼저 만들어 두는 기록 |
| 기준 궤적 세트 | 모든 단계에서 똑같이 돌리는 동작 목록 (`reference_trajectories.yaml`) |
| mock 하드웨어 | 명령을 그대로 상태로 돌려주는 가짜 하드웨어. 동역학이 없음 |
| 유지 토크 | 그 자세에서 팔이 처지지 않게 모터가 내야 하는 토크 |
| TCP | Tool Center Point. 그리퍼 끝에서 10 mm 안쪽 기준점 |
