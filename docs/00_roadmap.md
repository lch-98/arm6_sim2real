# 00. 전체 로드맵 (제작·Sim2Real 단계)

> 각 단계의 실제 진행 기록과 따라 하기 절차는 [docs 목차](README.md)의 해당 문서에 있다. 이 문서는 전체 계획이다.

모터를 한 번에 다 사지 않고, **시뮬레이션 기준선 → 모터 단품 → 시편 → J1~J3 → 손목 → 전체** 순서로 넓혀 간다.
단계마다 실물에서 측정한 값을 URDF/시뮬레이션에 되돌려 넣는 것이 Sim2Real의 핵심이다.
그래서 각 단계는 "무엇을 측정해서 어디에 반영하는지"를 산출물로 남긴다.

## 전체 흐름

| 단계 | 새로 구매 | 목표 | 산출물 |
|---|---|---|---|
| 0. 시뮬레이션 기준선 | 없음 | 실물과 비교할 기준 데이터 만들기 | 기준 궤적 세트, 시뮬레이션 로그 |
| 1. 모터 단품 벤치 | 모터 키트, H3510, 벤치 파워, 비상정지 | 통신·제어 모드 확인, 모터 특성 측정 | `motor_params.yaml`, 1축 하드웨어 인터페이스 |
| 2. 체결 설계·프린팅 시편 | 필라멘트, 인서트, 볼트 | 볼트 패턴 반영, 공차·소재 확정 | `CLR` 확정값, 슬라이서 설정, 실측 밀도 |
| 3. J1~J3 서브 어셈블리 | 베어링 61804·61802, SMPS | 어깨·팔꿈치 구동, 질량 식별 | 보정된 관성값, 영점 오프셋, 소프트 리밋 |
| 4. 손목·그리퍼 | (키트 4310 ×3, H3510 ×1), 61802, 피니언 | 손목·그리퍼 구동, 그리퍼 보정 | 그리퍼 스트로크·파지력, 전체 체인 식별 |
| 5. 전체 통합 | (선택) D435 | MoveIt 실기 구동, 안전 기능, 반복정밀도, 손목 카메라 | 실기 구동 런치, 반복정밀도 기록, 핸드-아이 결과 |
| 6. Sim2Real 루프 | 없음 | 식별값 반영, 랜덤화 범위 설정 | 갱신된 URDF·시뮬레이션 설정 |

모터 배정: J1·J2·J3 4340P, J4·J5·J6 4310, 그리퍼 H3510.
모터는 키트(4340P ×3, 4310 ×3)로 한 번에 구매하고 그리퍼용 H3510만 따로 산다. 단계별로는 필요한 모터만 꺼내 쓴다.

## 0. 시뮬레이션 기준선 (구매 전) — ✅ 완료 → [04_sim_baseline.md](04_sim_baseline.md)

**한 일**
1. `ros2_control` 정의 추가: mock 하드웨어(`mock_components/GenericSystem`)와 Gazebo(`gz_ros2_control`) 두 가지
2. 컨트롤러: `arm_controller`(joint1~6, JointTrajectoryController), `gripper_controller`(두 핑거), `joint_state_broadcaster`, 200 Hz
3. **기준 궤적 세트** 고정: `arm_bringup/config/reference_trajectories.yaml` (version 2)
   - (a) 관절별 사인 스윕 6개 (b) 정지 자세 12개 (c) 픽앤플레이스 1개
4. 기록·분석 도구: `run_reference.py`(궤적 재생 + rosbag 기록), `analyze_baseline.py`(추종 오차, 정지 자세 토크 vs 모델)

**산출물**: 기준 궤적 파일, mock·Gazebo 기준 bag, 분석 결과 (`docs/results/00_sim_baseline/`)

## 1. 모터 단품 벤치 테스트

**사용**: 키트의 4340P ×1, 4310 ×1 / **구매**: 전류 제한이 되는 벤치 파워(0~30 V), 비상정지 스위치 (상세: [05](05_motor_bench.md))
**준비물**: 기존 USB-CAN 어댑터, 120 Ω 종단저항 2개, 레버 시험용 프린팅 막대

**연결과 설정**
1. CAN 버스 양 끝에 120 Ω 종단저항. 첫 전원은 **벤치 파워 24 V, 전류 제한 낮게** 시작
2. Damiao 설정 프로그램으로 모터마다 CAN ID / Master ID / 1 Mbps / 제어 모드를 설정하고, 펌웨어 버전을 기록한다
3. PC에서 확인
   ```bash
   sudo ip link set can0 type can bitrate 1000000
   sudo ip link set can0 up
   candump -td can0          # 응답 프레임과 타임스탬프 확인
   ```
4. 구동 순서: 활성화 → 속도 모드 저속 → 위치 모드 → MIT 모드(kp, kd 작게 시작)

**측정 항목** (모델별로 기록)
| 항목 | 방법 | 반영처 |
|---|---|---|
| 절대 위치 유지 | 임의 각도에서 전원 껐다 켜기 → 위치값 비교 | 원점 복귀 필요 여부 결정 |
| 토크 보정 | 출력에 길이 L 레버 + 무게 m → 정지 유지 시 모터가 보고한 토크 vs m·g·L | 토크 상수 보정계수 |
| 마찰 | 여러 속도로 등속 회전 → 평균 토크 | 쿨롱·점성 마찰 (URDF `dynamics`) |
| 백래시 | 레버 끝을 손으로 양방향 밀며 각도 변화 측정 | 정밀도 한계, 랜덤화 범위 |
| 통신 지연 | 명령 프레임 → 응답 프레임 시간차 (candump 타임스탬프) | 시뮬레이션 지연 모델 |
| 발열 | 정격 근처 토크 유지하며 온도 기록 | 연속 사용 한계 |

**소프트웨어**
- 1축용 ros2_control 하드웨어 인터페이스 작성. OpenArm의 `openarm_hardware`(Damiao 대상)를 참고하면 빠르다
- **1자유도 진자 Sim2Real**: 레버+추를 URDF로 만들어 Gazebo와 실물에 같은 스윕을 넣고 응답 비교 → 마찰·감쇠 값을 맞춘다

**산출물**: `motor_params.yaml` (모델별 토크 보정, 마찰, 백래시, 지연), 1축 하드웨어 인터페이스

## 2. 체결 설계·프린팅 시편

**할 일**
1. 받은 모터의 공식 도면(STEP)으로 하우징·출력 플랜지 볼트 패턴을 `generate_cad.py`에 반영한다.
   - 요크판·캔(하우징 체결), 어댑터·원판(출력 체결), 고정 링·베어링 캡(인서트 체결)
2. **공차 시편** 출력: 베어링 시트 링(`CLR` 0.1 / 0.2 / 0.3), 핀, 모터 포켓 링, 열압입 인서트 시편
3. 소재 결정: 구조 부품은 PETG 권장(PLA보다 하중을 오래 걸었을 때 덜 처짐). PLA는 시편·형상 확인용
4. 시편 무게를 재서 `PRINT_FILL`(실효 충진율)을 실측값으로 바꾼다 → URDF 질량이 실물에 가까워진다

**산출물**: 확정 `CLR`, 슬라이서 설정(벽 수, 인필, 출력 방향), 실측 `PRINT_FILL`

## 3. J1~J3 서브 어셈블리

**사용**: 키트의 4340P ×3 / **구매**: 베어링 61804 ×1, 61802 ×1, 24 V SMPS
**프린팅**: base_link, link1, link2, link3 + 어댑터·핀·캡·고정 링

**더미 질량**: link3의 URDF 질량에는 J4 모터(약 0.3 kg)가 포함되어 있다.
실물에서는 J4 캔에 같은 무게의 더미 추(너트 등을 저울로 맞춤)를 넣어 URDF와 일치시킨다.
J4 출력면 위치에 시험 추를 추가로 달 수 있다.
```bash
ros2 launch arm_description display.launch.py stage:=j1to3 test_mass:=0.2
```
참고로 이 단계에서 상완·전완을 수평으로 편 자세의 중력 토크는 시험 추 0.2 kg 기준 J2 약 2.2 N·m, J3 약 0.6 N·m다 (시뮬레이션 값).

**순서**
1. 조립 (README의 조립 순서). 배선은 상완 내부 통로로
2. 한 관절씩 구동: J1 → J2 → J3. 처음엔 낮은 kp, 좁은 소프트 리밋, 중력 보상 없음
3. **영점 설정**: 홈 자세(상완 수직, 전완 수평)를 맞춘 뒤 각 모터 영점 저장. 수평계나 프린팅 각도 지그 사용
4. **중력 토크 식별**: 0단계의 정지 자세 목록에서 관절 토크를 측정 → URDF의 질량·무게중심을 최소자승으로 보정
5. 0단계 기준 궤적을 실물과 Gazebo에서 같이 돌려 추종 오차·토크를 비교
6. 처짐 확인: 수평 자세에서 끝단 처짐 측정 → 프린팅 강성이 부족하면 벽 수·인필·형상 보강
7. 관절 한계 확인: 실제 간섭 각도를 재고 소프트 리밋을 그보다 안쪽으로

**산출물**: 보정된 관성값(link1~3), 관절별 영점 오프셋, 소프트 리밋, J1~J3 비교 로그

## 4. 손목·그리퍼

**사용**: 키트의 4310 ×3 (J4, J5, J6), H3510 ×1 (그리퍼) / **구매**: 베어링 61802 ×1, 평기어 모듈 1 20T ×1
**프린팅**: link4, link5, link6, 핑거 2개 (+ TPU 패드)

**순서**
1. 새 모터는 1단계 절차를 축약해서 단품 확인 (ID 설정, 방향, 토크 보정)
2. **H3510 절대 위치 확인**: 전원 재투입 후 위치 유지 여부. 유지되지 않으면 그리퍼는 "닫힘 방향으로 낮은 전류로 접촉 → 영점" 원점 복귀 루틴을 만든다
3. 그리퍼 보정: 피니언 회전각 ↔ 핑거 이동량, 파지력(주방 저울 사이에 끼워 측정) ↔ 명령 토크
4. 더미 추를 빼고 손목 조립 → 3단계 식별(4, 5번)을 전체 체인으로 반복

**산출물**: 그리퍼 보정표, 전체 체인 관성값, 손목 영점

## 5. 전체 통합

1. MoveIt 설정 (`arm_moveit_config`), 실기 하드웨어 인터페이스로 계획·실행
2. 안전 기능
   - 비상정지는 **모터 전원 라인**을 끊는다 (소프트웨어 정지와 별개)
   - 모터 측 통신 타임아웃, 전류·토크 제한, 소프트 리밋
   - CAN 버스 오류(bus-off) 감지 시 정지
3. 반복정밀도 측정: 같은 목표 자세를 여러 번 왕복 → 끝단 위치 편차 기록 (모눈종이·다이얼 게이지)

**산출물**: 실기 구동 런치 파일, 반복정밀도 기록

### 5-1. 손목 카메라 (D435, 필요해질 때)

**구매**: RealSense D435, 짧은 USB-C 케이블(USB 3) / **프린팅**: `camera__bracket.stl`, `camera__clamp.stl`
1. 실물의 삼각대 나사·뒷면 M3 위치를 재서 필요하면 브래킷에 구멍을 추가 (`make_camera()`)
2. 브래킷 → 그리퍼 바디 패드에 M3 2개, 카메라 올리고 클램프로 고정
3. 배선: J6가 돌아도 케이블이 당기지 않게 여유 루프를 두고, 그 범위로 J6 소프트 리밋을 줄인다
4. **핸드-아이 캘리브레이션**: 체커보드나 ArUco 보드를 여러 자세에서 촬영해 `link6 → camera_link` 실제 변환을 구한다 (예: easy_handeye2). 결과로 URDF의 `CAM` 위치·각도를 갱신
5. 질량: 카메라+마운트 실측 무게로 URDF 갱신 후 3단계 중력 식별을 손목 자세 몇 개로 다시 확인
6. 깊이 한계: 카메라~TCP가 약 85 mm로 D435 최소 깊이 거리(0.105 m)보다 가깝다. 파지 직전 구간은 깊이가 비므로, 인식은 접근 거리에서 끝내도록 시나리오를 짠다


---

## 6. Sim2Real 루프

1. 식별값을 URDF·시뮬레이션에 반영: 질량·무게중심, 관절 마찰·감쇠, 토크 보정, 통신 지연
2. 남는 오차 크기를 근거로 시뮬레이션 랜덤화 범위를 정한다 (질량, 마찰, 지연, 백래시)
3. 시뮬레이션에서 만든 제어기·정책을 실기에 옮길 때는 같은 기준 궤적으로 먼저 비교하고, 속도·토크 한계를 낮춘 상태에서 시작한다
4. 하드웨어를 바꾸면(링크 형상, 모터 교체) 해당 단계의 식별을 다시 한다

## 소모품·도구

**전원·안전**
| 품목 | 비고 |
|---|---|
| 벤치 파워 (0~30 V, 전류 제한) | 1단계 단품 테스트용. 처음 전원 넣을 때 사고를 막아 줌 |
| 24 V SMPS (예: Mean Well LRS-350-24, 24 V 14.6 A) | 3단계부터. 모터 7개 동시 가속을 고려해 여유 있게 |
| 비상정지 스위치 (버섯형, 자기유지) | 모터 전원 라인 차단용 |
| 퓨즈 + 홀더, 전원 스위치 | SMPS 출력 측 |
| 실리콘 전선 (전원용 굵은 것, CAN용 꼬임선) | |
| 전원 커넥터·CAN 커넥터 | 모터 커넥터 규격은 받은 제품을 보고 맞춰서 구매 |
| 120 Ω 종단저항 ×2 | CAN 버스 양 끝 |

24 V용 Damiao 드라이버는 과전압 보호가 32 V로 표기되어 있다. 팔을 급하게 감속하면 모터가 전압을 되돌려 보낼 수 있으므로, 처음에는 감속을 완만하게 설정하고 전원 전압을 모니터링한다.

**프린팅**
| 품목 | 비고 |
|---|---|
| PETG 필라멘트 | 구조 부품 |
| PLA 필라멘트 | 시편·형상 확인 |
| TPU 필라멘트 | 핑거 패드 |
| 황동 열압입 인서트 (M2.5, M3) | 반복 체결 부위 |
| 인서트용 인두 팁 | |
| 볼트 세트 (M2.5, M3, M4 / 렌치볼트·접시머리) | 모터 볼트 규격은 도면 확인 후 |

**공구**
| 품목 | 용도 |
|---|---|
| 디지털 버니어 캘리퍼스 | 공차·시편 측정 |
| 육각렌치 세트 | 조립 |
| 멀티미터 | 전원·CAN 저항(종단 2개면 약 60 Ω) 확인 |
| 디버링 툴, 줄 | 프린팅 후가공 |
| 바이스 또는 클램프 | 베어링 압입 |
| 저울 (0.1 g 단위 + 수 kg) | 질량 측정, 더미 추, 파지력 |
| 디지털 각도계 또는 수평계 | 영점 설정 |
| 케이블 타이, 배선 클립 | 배선 정리 |
