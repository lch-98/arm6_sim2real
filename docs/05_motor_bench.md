# 05. 모터 단품 벤치 (로드맵 1단계)

> 상태: **준비물 정리 완료, 부품 도착 대기**. 진행하면서 절차와 결과를 이 문서에 채운다.

목표: 모터 2개(4340, 4310)를 팔에 달기 전에 책상 위에서 돌려 보고, **통신·제어 방법을 확정하고 모터 특성을 측정**한다.
여기서 측정한 값(토크 보정, 마찰, 지연)이 시뮬레이션의 모터 모델이 된다.

## 1. 연결 구성

```
  [PC (Ubuntu)] ──USB── [USB-CAN 어댑터] ──CAN_H/CAN_L──┐
                         (종단저항 120 Ω ON)            │
                                                          ▼
  [벤치 파워 24 V] ──[퓨즈]──[비상정지]──24V/GND──▶ [XT30(2+2) 분기 케이블]
                                                          │
                                         ┌────────────────┘
                                         ▼
                               [DM-J4340] ═XT30(2+2)═ [DM-J4310] ── [종단저항 120 Ω]
                                 ▲  ↑ 데이지 체인 (전원 + CAN 같이)
                                 │
  [Windows PC] ──USB── [USB-TTL] ──GH1.25 3핀── (설정할 때만 한 대씩)
```

- Damiao J 시리즈는 **XT30(2+2)** 커넥터 하나에 전원(24V/GND)과 CAN(CAN_H/CAN_L)이 같이 들어 있다. 모터마다 이 커넥터가 **2개**라서 모터끼리 이어 붙일 수 있다(데이지 체인)
- **GH1.25 3핀**(TX/RX/GND)은 설정용 시리얼 포트. CAN ID, 제어 모드 같은 파라미터를 바꿀 때만 쓴다
- 드라이버가 모터 안에 있으므로 **별도 모터 제어기(드라이버, MCU)는 필요 없다**. PC가 CAN으로 직접 명령한다

## 2. 준비물

### 2-1. 구매 (이번 단계)

| 품목 | 수량 | 고를 때 확인할 것 | 용도 |
|---|---|---|---|
| Damiao DM-J4340-2EC | 1 | **24 V 버전**. 판매처에 2D/3D 도면(STEP) 요청 | 나중에 J2 |
| Damiao DM-J4310-2EC | 1 | **24 V 버전**. 펌웨어 버전(V1.1/V1.2) 기록. 나중에 J4·J5용을 살 때 같은 버전으로 | 나중에 J1 |
| USB-CAN 어댑터 (SocketCAN 지원) | 1 | 아래 2-2 참고. 이미 가진 어댑터가 SocketCAN으로 잡히면 생략 | PC ↔ CAN 버스 |
| USB-TTL 변환 모듈 (3.3 V 신호) | 1 | CP2102 또는 CH340 계열. 신호 전압 3.3 V | 모터 설정 (시리얼) |
| GH1.25 3핀 케이블 | 1~2 | 모터에 포함되는지 먼저 확인 | USB-TTL ↔ 모터 |
| XT30(2+2) 케이블 (수-수) | 1 | 모터 사이 연결용. 모터에 포함되는지 먼저 확인 | 모터 ↔ 모터 |
| XT30(2+2) 수 커넥터 + 전선 (또는 피그테일) | 2 | 한쪽 끝이 전선으로 풀린 것. 전원선 18 AWG 정도, CAN은 꼬임선 | 전원·어댑터 분기, 종단저항 |
| 120 Ω 저항 | 2 | 1/4 W | CAN 버스 양 끝 종단 (어댑터에 내장 스위치가 있으면 1개) |
| 벤치 파워 (0~30 V, 전류 제한) | 1 | **전류 제한(CC) 기능 필수**, 5 A 이상 | 첫 전원 투입 |
| 비상정지 스위치 | 1 | 버섯형, 누르면 잠기는(자기유지) 타입, 정격 10 A 이상 | 모터 전원 차단 |
| 퓨즈 + 홀더 | 1 | 블레이드 퓨즈 5 A로 시작 | 단락 보호 |

### 2-2. USB-CAN 어댑터 고르기

| 선택지 | Linux (ROS) | Windows 설정 프로그램 | 비고 |
|---|---|---|---|
| 지금 가진 USB-CAN 어댑터 | 꽂았을 때 `ip link`에 `can0`이 생기면 그대로 사용 | 해당 없음 | 먼저 확인 |
| candleLight/gs_usb 계열 (예: CANable + candleLight 펌웨어) | 커널 기본 드라이버로 `can0` | 해당 없음 | 범용, 권장 |
| Damiao USB-CAN 모듈 (DM-USBCU1, CAN 버전) | 전용 방식 (SocketCAN 여부 확인 필요) | Damiao 디버깅 어시스턴트와 바로 연동 | 설정용으로 편함. 판매처 표시가 약 $15 |

**정리**: ROS 제어용으로는 **SocketCAN 어댑터**(지금 가진 것 또는 candleLight 계열), 모터 설정용으로는 **USB-TTL + GH1.25**를 쓴다.
Damiao 모듈은 있으면 Windows에서 설정·펌웨어 업데이트가 편하지만 필수는 아니다.

지금 가진 어댑터 확인:

```bash
lsusb                 # 장치가 잡히는지
ip link | grep can    # can0 이 보이면 SocketCAN 어댑터
ls /dev/ttyACM* /dev/ttyUSB*   # 대신 이쪽에 생기면 시리얼(slcan) 방식 → slcand 로 can0 생성 가능
```

### 2-3. 이미 있거나 다음 단계와 같이 쓰는 것

| 품목 | 용도 |
|---|---|
| 멀티미터 | 전원 극성, CAN 종단 저항 확인 (전원 끈 상태에서 CAN_H–CAN_L 약 60 Ω이면 정상) |
| 납땜 인두, 수축튜브, 와이어 스트리퍼 | XT30 케이블·종단저항 만들기 |
| 디지털 캘리퍼스 | 모터 체결 구멍 실측 (도면이 없을 때) |
| 주방 저울 (0.1 g, 최대 수 kg) | 시험 추 무게 측정 |
| 시험 추 (100~500 g) | 토크 보정. 볼트·너트 묶음을 저울로 재서 써도 됨 |
| 바이스 또는 클램프 | 모터 고정 (첫 구동 시 모터가 튀지 않게) |
| 볼트 세트 M2.5 / M3 | 출력 플랜지에 레버 체결 (규격은 도면 확인 후) |
| Windows PC | Damiao 디버깅 어시스턴트 실행 |

### 2-4. 소프트웨어

```bash
sudo apt install can-utils     # candump, cansend
pip install python-can         # 파이썬에서 CAN 테스트
```

Windows: Damiao 디버깅 어시스턴트(판매처·Damiao 자료실에서 받음). CAN ID, Master ID, 제어 모드, 영점, P_MAX·V_MAX·T_MAX를 설정한다.

## 3. 모터가 오면 먼저 할 일

1. **치수 실측·도면 확보**: 하우징·출력 플랜지 볼트 구멍(개수, 피치원 지름, 나사 규격). 벤치 고정 지그와 단계 2(체결 설계)에 필요
2. 펌웨어 버전, 정격 토크·속도(사양서 기준) 기록 → `docs/01_design.md` 액추에이터 표 갱신
3. 포함된 케이블 확인 → 부족한 XT30(2+2)·GH1.25 케이블만 추가 구매

## 4. 측정 항목 (진행하면서 채움)

| 항목 | 방법 | 반영처 |
|---|---|---|
| 절대 위치 유지 | 임의 각도에서 전원 껐다 켜기 | 원점 복귀 필요 여부 |
| 토크 보정 | 레버 + 추를 정지 유지할 때 모터 보고 토크 vs m·g·L | 토크 보정계수 |
| 마찰 | 여러 속도로 등속 회전 → 평균 토크 | URDF `dynamics` (마찰·감쇠) |
| 백래시 | 레버 끝을 양방향으로 밀며 각도 변화 | 랜덤화 범위 |
| 통신 지연 | 명령 → 응답 프레임 시간차 (`candump -td`) | 시뮬레이션 지연 모델 |
| 위치 루프 응답 | 기준 스윕(1축)을 실물에 돌려 추종 오차 측정 | Gazebo 대비 모터 모델 |
| 발열 | 정격 근처 토크 유지하며 온도 기록 | 연속 사용 한계 |
