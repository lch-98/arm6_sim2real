# arm_description

소형 6축 관절형 매니퓰레이터 + 랙·피니언 평행 그리퍼의 형상(CAD)과 URDF 패키지.
구조 부품은 전부 3D 프린팅이고, 액추에이터·베어링·피니언 기어만 구매한다.
통신은 일반 CAN(CAN 2.0, 1 Mbps). ROS 2 Humble / Ubuntu 22.04 기준.

제작 순서와 Sim2Real 진행 방법은 저장소의 [docs/](../docs/README.md) 참고.

## 구조

| 관절 | 부모 → 자식 | 원점 오프셋 | 축 | 범위 | 액추에이터 |
|---|---|---|---|---|---|
| joint1 (베이스 요) | base_link → link1 | z 66 mm | z | ±170° | DM-J4340P-2EC |
| joint2 (어깨 피치) | link1 → link2 | z 68 mm | y | ±110° | DM-J4340P-2EC |
| joint3 (팔꿈치 피치) | link2 → link3 | z 170 mm | y | −150° ~ +32° | DM-J4340P-2EC |
| joint4 (전완 롤) | link3 → link4 | x 115 mm | x | ±170° | DM-J4310-2EC |
| joint5 (손목 피치) | link4 → link5 | x 100 mm | y | ±110° | DM-J4310-2EC |
| joint6 (손목 롤) | link5 → link6 | x 95 mm | x | ±170° | DM-J4310-2EC |
| finger_left_joint | link6 → finger_left | x 56 mm | +y (프리즘) | 0 ~ 20 mm | DM-H3510 + 피니언 |
| finger_right_joint | link6 → finger_right | x 56 mm | −y (mimic) | 0 ~ 20 mm | (같은 피니언) |

- 홈 자세(전 관절 0)는 상완 수직 + 전완~그리퍼 수평의 ㄱ자 형태
- 수평 최대 도달 거리(J1 축 ~ TCP) 0.566 m, 전체 질량 약 2.93 kg (손목 카메라 포함, 아래 가정 기준)
- 프레임: `tool0` = J6 출력면, `tcp` = 핑거 끝에서 10 mm 안쪽
- joint2 ±110°: 단독으로는 142°에서 베이스와 간섭
- joint3 상한 +32°: 전완 J4 캔이 상완 빔에 38°에서 닿음
- 베이스 높이 66 mm (J1 4340P 수납). 베이스 플랜지: 맞변 120 mm 팔각형, 4-Ø5.5 (M5) 볼트 구멍 PCD 98 mm (45° 방향)

### 관절 구성 방식

- **피치 관절(J2, J3, J5)**: 일체형 요크. −y 판 바깥에 액추에이터를 달고, 출력은 판 구멍을 지나 **어댑터 원판**을 거쳐 자식 링크 허브를 돌린다. +y 판에는 지지 베어링(J2: 61804, J3·J5: 61802)이 압입되고, **핀**이 베어링 내륜을 지나 허브에 꽂힌다.
  조립 순서: 허브를 요크 사이에 넣기 → 어댑터를 바깥에서 넣어 허브에 체결 → 액추에이터 장착 → 베어링 압입 → 핀 삽입 → 베어링 캡
- **롤 관절(J4, J6)과 그리퍼**: 링크 끝의 원통 캔에 액추에이터를 앞에서 넣고 고정 링으로 누른다. 다음 링크는 액추에이터 출력면에 원판으로 체결된다.
- **J1**: 베이스 기둥 안에 액추에이터가 들어가고, link1 원판이 출력면에 체결된다.
- **그리퍼**: H3510 → 모듈 1, 20T 피니언(구매) → 위·아래 랙 2개(핑거와 일체 프린팅)가 반대 방향으로 이동. 최대 벌림 약 44 mm

### 손목 카메라 (Intel RealSense D435)

- 그리퍼 바디 위 패드(M3 인서트 2개)에 **브래킷**을 체결하고, 카메라를 받침에 올린 뒤 **클램프**로 윗면 뒤쪽을 눌러 고정한다 (클램프는 브래킷 뒤판에 M3 셀프태핑 2개)
- D435의 삼각대 나사(1/4-20)·뒷면 M3 위치와 간격은 공개 자료에서 확인하지 못해, 마운트는 카메라 외형(90×25×25 mm)으로 잡는 방식이다. 실물을 받으면 구멍을 재서 추가할 수 있다
- 받침 양 끝은 열려 있어 USB-C 케이블이 어느 쪽이든 빠진다
- 위치: link6 기준 카메라 본체 중심 (x 20, z 54) mm, 아래로 25° 숙임 (`CAM` 딕셔너리에서 변경)
  - TCP는 광축에서 약 14° 아래, 그리퍼 앞 200 mm 지점은 약 13° 위 → 둘 다 RGB 화각(세로 ±21°) 안
  - 카메라~TCP 거리 약 85 mm로 D435 최소 깊이 거리(Min-Z 0.105 m)보다 가깝다. **집는 순간의 핑거 주변은 깊이값이 안 나오고 RGB만 보인다.** 접근 단계(10 cm 이상 떨어진 거리)에서 깊이로 물체를 찾고, 마지막 구간은 RGB나 미리 계산한 자세로 처리하는 구성을 가정
- TF 프레임: `camera_link`(본체 중심, x = 시선 방향, RealSense 드라이버와 같은 이름), `camera_optical_nominal`(공칭 광학 프레임). 드라이버를 쓸 때는 드라이버가 `camera_link` 아래 실제 센서 프레임을 내보낸다
- J6가 회전하면 카메라도 같이 돈다. USB 케이블이 감기지 않도록 J6 사용 범위를 실제 배선 여유에 맞춰 줄이는 것을 권장
- 카메라 없이 쓰려면 `camera:=none`

## 일반 CAN 대역폭

CAN 2.0A 8바이트 프레임은 111비트, 비트 스터핑 최악 135비트 → 1 Mbps에서 프레임당 약 0.135 ms.
모터 7개 × (명령 + 응답) = 14 프레임/주기.

| 제어 주기 | 버스 부하 |
|---|---|
| 100 Hz | 19% |
| 200 Hz | 38% |
| 250 Hz | 47% |
| 500 Hz | 94% |

200~250 Hz 제어까지 여유가 있으므로 이 팔에는 CAN FD가 필요하지 않다.

## 폴더

```
print/*.stl                  프린팅할 파일 전체 (부품별 개별 파일) + parts_list.txt
cad/generate_cad.py          형상 생성 스크립트 (치수·액추에이터·베어링은 여기서 관리)
cad/step/*.step              부품별 STEP
cad/arm_assembly.step        홈 자세 조립 STEP (액추에이터 외형 포함)
meshes/*_body.stl            URDF 표시용 링크 본체 (흰색)
meshes/*_accent.stl          URDF 표시용 캡·어댑터·핀·패드·피니언 (주황)
meshes/*_motor.stl           URDF 표시용 액추에이터 외형 (회색)
meshes/*_collision.stl       충돌 형상 (위 셋을 합친 것)
urdf/arm_macro.xacro         팔 매크로
urdf/arm.urdf.xacro          단독 실행용 최상위 파일
urdf/generated/arm_properties.xacro   스크립트가 생성: 관절 오프셋 + 질량/관성
launch/display.launch.py
scripts/joint_sweep.py       데모용 관절 스윕 노드
```

## 빌드 및 실행

```bash
# 설치·빌드는 docs/03_dev_setup.md 참고

ros2 launch arm_description display.launch.py                  # 슬라이더로 관절 조작
ros2 launch arm_description display.launch.py demo:=true       # 관절 자동 스윕
ros2 launch arm_description display.launch.py stage:=j1to3 test_mass:=0.2   # J1~J3 서브 어셈블리
ros2 launch arm_description display.launch.py camera:=none                  # 손목 카메라 없이
```

ros2_control(mock / Gazebo)로 구동하는 방법은 `arm_bringup` 패키지와 [docs/04_sim_baseline.md](../docs/04_sim_baseline.md) 참고.

## 치수 변경

```bash
pip install cadquery
python3 cad/generate_cad.py   # print/, meshes/, cad/step, urdf/generated 재생성
colcon build --packages-select arm_description
```

- 링크 길이·요크 폭: `P`
- 액추에이터 모델 교체: `ACT`(외경·높이·질량), `JOINT_ACT`(관절별 배정). 요크·캔·허브 크기는 액추에이터 치수에서 자동으로 계산된다
- 베어링: `BRG`, `JOINT_BRG`
- 프린터 공차: `CLR` (기본 반경 0.3 mm). 시험 출력 후 조정

## 검증 내용 (ROS 없는 환경에서 Python으로 수행)

- xacro 전개 정상, 각 관절을 하나씩 한계값까지 돌렸을 때 자기간섭 없음 (액추에이터 외형 포함 충돌 메쉬 기준)
- 손목 카메라: J5(±110°) × J6(전 범위) 조합에서 간섭 없음. J5를 −120°까지 숙이면 마운트가 link3에 닿음
- 팔을 수평으로 완전히 편 자세에서 정적 중력 토크

| 가반하중 | J2 (정격 9 N·m) | J3 (정격 9 N·m) | J5 (정격 3 N·m) |
|---|---|---|---|
| 0 kg | 6.1 N·m (68%) | 3.0 N·m (34%) | 0.55 N·m (18%) |
| 0.3 kg | 7.8 N·m (87%) | 4.2 N·m (46%) | 1.1 N·m (36%) |
| 0.5 kg | 8.9 N·m (99%) | 5.0 N·m (55%) | 1.4 N·m (48%) |

(손목 카메라 + 마운트 포함) → 설계 가반하중 **0.3 kg** (최악 자세 기준). 한계는 J2이며 정격(9 N·m) 기준 정적 최대는 약 0.50 kg.
손목 자세를 전부 훑었을 때 J6 최대 중력 토크는 0.048 N·m (4310 정격 3 N·m의 2%).

## 주의할 점 (프린팅 전 필수 확인)

1. **액추에이터 체결 구멍이 아직 없음.** 액추에이터는 판매처 사양표의 외경×높이로 만든 원기둥이다. 하우징 체결 볼트와 출력 플랜지 볼트 패턴은 Damiao 공식 도면(STEP)으로 확인한 뒤 요크판·캔·어댑터·원판에 구멍을 추가해야 한다.
2. **질량 가정**: 프린팅 부품은 PLA 1240 kg/m³ × 실효 충진율 0.5(`PRINT_FILL`), 액추에이터는 사양표 질량. 베어링·볼트·배선은 미포함
3. **정격값**: 판매처마다 표기가 다른 경우 낮은 값을 사용했다 (4340P: 9 N·m / 36 rpm — 판매처에 따라 정격 12 N·m 표기, 4310: 3 N·m / 120 rpm, H3510: 0.18 N·m / 500 rpm). 받은 제품 사양서로 재확인
4. **H3510 엔코더**: 직결 구동이라 엔코더 1회전 = 출력 1회전이다. 전원을 켰을 때 절대 위치를 바로 읽을 수 있는지는 제품 매뉴얼로 확인할 것
5. **배선**: 액추에이터가 중공축이 아니므로 케이블은 상완·전완 내부 통로와 배선 구멍, 외부 클립으로 정리한다
